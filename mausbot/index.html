Quero instalar o OpenMausBot (https://github.com/milind-soni/OpenMausBot), o app de código aberto que junta o Claude Code, o Codex e o Grok num time de agentes. Faça por mim, seguindo só o README oficial desse repositório:

1. Veja qual é o meu sistema (Mac com chip Apple, Mac Intel, Windows ou Ubuntu) e se o Node.js é a versão 24 ou mais nova. Se não for, me diga em uma frase como atualizar e espere eu dizer "pronto".
2. Instale pelo caminho do terminal que o README mostra: npm install -g openmausbot
3. Abra o openmausbot e me guie no assistente da primeira vez, um passo por vez: qual provedor escolher (o Claude Code que eu já uso), entrar na conta e escolher o modelo. Conectar o celular pode pular.
4. Antes de qualquer coisa que peça senha, login, chave de API ou pagamento, pare e me pergunte. Não digite nenhuma senha por mim.
5. No fim, me explique em 3 linhas: como criar o meu primeiro bot, como mudar o nível de aprovação para ele me perguntar antes de agir, e como fechar e abrir o app de novo.

Antes de começar

  • O app é gratuito, mas o uso das IAs é o seu: as suas assinaturas ou chaves de API. O “OMB Cloud” hospedado é um serviço pago e opcional.
  • Por padrão, cada bot começa em “Full access” (o modo mais solto). Você pode mudar o nível de aprovação por bot ou conversa.
  • O projeto não tem token nem criptomoeda: qualquer moeda com esse nome não é deles.
  • A pasta enterprise/ do repositório tem outra licença.

3

Na primeira vez, o assistente pergunta

Qual provedor (ChatGPT/Codex, Claude Code ou chave de API), você entra na conta, escolhe o modelo e salva. Conectar o celular é opcional (“Skip for now”). O app abre no navegador, num endereço local. Mantenha o terminal aberto; Ctrl+C para o servidor sem apagar nada.

4

Use

Cada bot é um contato na barra lateral. Você escolhe o modelo de cada um (Claude e Codex lado a lado) e troca no meio da conversa. Quando um bot vai rodar comando, editar arquivo ou tem uma pergunta, chega um cartão para você Permitir ou Negar.

5

Times prontos

Dá para instalar um time inteiro a partir de um arquivo: bots, o “Chief of Staff”, canais e rotinas. As conexões ficam desligadas até você aprovar e as rotinas chegam pausadas.
